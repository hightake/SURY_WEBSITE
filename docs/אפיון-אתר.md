# SURY – אפיון אתר

עודכן: 10.11.2026

## מטרות ועקרונות מנחים

האתר יעלה כאתר תדמיתי, אך ייבנה מהיום על תשתית שמאפשרת להפעיל מכירה אונליין בלי לבנות מחדש. כל התוכן באתר נשאב ממסד נתונים ומנוהל דרך ממשק ניהול, ללא תוכן קשיח בקוד.

- **בהירות:** הלקוחה מבינה מיד את חמשת העולמות של SURY ומגיעה לכל מוצר בלחיצה אחת או שתיים.
- **תפריט לפי קטגוריות:** שמות המותגים (Soie La, CLOA, BLANCHE, MODO, Bandana Air) משולבים בתוך הקטגוריות, באנגלית לצד הסבר בעברית.
- **מוכנות למכירה:** לכל מוצר יש עמוד פירוט מלא כבר עכשיו. שדות המכירה (מחיר, מלאי, וריאציות) קיימים במבנה הנתונים ומוסתרים בתצוגה עד להפעלה.
- **תוכן דינאמי:** קטגוריות, מוצרים, קולקציות, טקסטים ותמונות מנוהלים מהאדמין. דף הבית, עמודי הקטגוריה ועמודי המוצר נבנים מהנתונים בזמן אמת.
- **מתג מצב אתר:** הגדרה מרכזית אחת באדמין – "תדמיתי" / "מכירתי" – שמציגה או מסתירה מחירים, כפתורי רכישה, סל קניות ועמודי חנות.

## תפריט ועץ קטגוריות

התפריט הראשי כולל חמש קטגוריות מוצר ועמודים קבועים. העץ תומך בשלוש רמות (קטגוריה › תת־קטגוריה › תת־תת־קטגוריה), ולכן בדסקטופ התפריט ייפתח כמגה־מניו ובמובייל כאקורדיון.

    - כובעים קלאסיים עם קישוט

    - MODO קלאסי
    - עליוניות וקשתות למודולרי
    - פטנט קשירה

    - **בסיסים לכובעים** (חדש) – שבעה סוגי בסיסים: עמידים, מונעי החלקה, ניתנים להגדלה ולהקטנה
    - **קישוטים ואקססוריז** (חדש)

**הערות לאפיון העץ:**

- **בסיסים:** הבסיסים משמשים גם למטפחות Soie La ולקשירות. מוצר בסיס יוכל לשייך לכמה קטגוריות (שיוך מרובה), כך שיופיע גם בקטגוריית מטפחות וצעיפים בלי לשכפל אותו.
- **קשתות:** קיימת חפיפה בין "עליוניות וקשתות למודולרי" לבין "קשתות" בקישוטים. יש לברר אם מדובר באותם מוצרים.
- **סדר ושמות:** סדר הקטגוריות, שמותיהן והחשיפה שלהן בתפריט נקבעים מהאדמין ואינם קבועים בקוד.

- **מדיניות פרטיות, הצהרת נגישות, תקנון** – עמודי טקסט הנערכים מהאדמין; התקנון יידרש בשלב המכירה.

## עמוד קטגוריה ועמוד מוצר

לכל מוצר עמוד פירוט משלו כבר בשלב התדמיתי; בשלב המכירה אותו עמוד מקבל מחיר, בחירת וריאציה וכפתור הוספה לסל.

**עמוד קטגוריה**

- תמונת אווירה ומשפט פתיחה (נערכים לכל קטגוריה).
- כרטיסי תתי־קטגוריות: תמונה + שם + שורת הסבר.
- גריד מוצרים: תמונה, שם, שורת תיאור קצרה; תווית "חדש" / "מהדורה מוגבלת" לפי סימון באדמין.
- סינון לפי תת־קטגוריה וצבע; מיון לפי חדש / מומלץ (ובשלב המכירה גם לפי מחיר).
- פירורי לחם (Breadcrumbs) בכל עמוד.

**עמוד מוצר – מה מוצג**

| אזור | שלב תדמיתי | שלב מכירתי |
| --- | --- | --- |
| גלריית תמונות + וידאו | ✓ | ✓ |
| שם, מותג, תיאור קצר ומלא | ✓ | ✓ |
| מפרט: חומר, משקל משי (Momme), מידות, הוראות טיפול | ✓ | ✓ |
| צבעים / דגמים זמינים | ✓ (לתצוגה) | ✓ (לבחירה) |
| התאמה לסוג בסיס / מבנה ראש (FIT SURY) | ✓ | ✓ |
| מוצרים משלימים (בסיס תואם, קישוט, סט) | ✓ | ✓ |
| כפתור "לפרטים ולהזמנה בוואטסאפ" עם שם המוצר בהודעה | ✓ | אופציונלי |
| מחיר, מחיר מבצע, מלאי | – | ✓ |
| בחירת וריאציה, כמות, הוספה לסל | – | ✓ |
| מדריך מידות / התאמה | ✓ | ✓ |

**וריאציות:** מוצר מורכב ממוצר־אב ומווריאציות (צבע, מידה/היקף ראש, סוג בסיס). לכל וריאציה מק"ט, תמונה, ובעתיד מחיר ומלאי משלה.

**מהדורות קטנות:** שדה כמות מהדורה (לדוגמה Soie La) ותווית "נותרו X" שתופעל רק בשלב המכירה.

**סטים:** מוצר מסוג "סט" (למשל כותונת + בנדנה, סינר + קשתות) מקשר למוצרים שבו ומציג אותם בעמוד.

## ממשק ניהול (אדמין)

ממשק ניהול בעברית (RTL), מאובטח בהתחברות, שבו הלקוחה מעדכנת את כל תוכן האתר בלי מפתחת. כל שינוי שנשמר מופיע באתר מיד (או בתאריך פרסום שנקבע).

**הרשאות ואבטחה**

| תפקיד | מה מותר |
| --- | --- |
| מנהלת ראשית | הכול, כולל ניהול משתמשים, הגדרות אתר ומתג מצב תדמיתי/מכירתי |
| עורכת תוכן | קטגוריות, מוצרים, קולקציות, מדיה ותכני עמודים; ללא משתמשים והגדרות |
| צפייה בפניות | צפייה בפניות מטופס צור קשר בלבד |

- התחברות עם סיסמה חזקה + אימות דו־שלבי למנהלת הראשית.
- נעילה לאחר ניסיונות כושלים, ניתוק אוטומטי, יומן פעולות (מי שינה מה ומתי).
- כתובת האדמין אינה מקושרת מהאתר הציבורי.

**מודולי ניהול**

1. **קטגוריות** – הוספה, עריכה, מחיקה; שיוך לקטגוריית אב (עד 3 רמות); שם בעברית ובאנגלית, טקסט פתיחה, תמונת שער, תמונת אווירה; סדר בגרירה; הצגה/הסתרה בתפריט.
2. **מוצרים** – כל שדות עמוד המוצר; שיוך לכמה קטגוריות; וריאציות; גלריה עם סדר בגרירה; מוצרים משלימים; סטטוס טיוטה/פורסם/מוסתר; תוויות (חדש, מהדורה מוגבלת). שדות המכירה קיימים ומוסתרים עד להפעלה.
3. **קולקציות** – קולקציה = שם, תיאור, תמונת שער, תאריכי תצוגה, ורשימת פריטים. לכל פריט: תמונה + טקסט + קישור אופציונלי למוצר. שיוך הקולקציה לקטגוריה אחת או יותר ולדף הבית.
4. **ספריית מדיה** – העלאה מרובה בגרירה; דחיסה והקטנה אוטומטית; חיתוך למבנים קבועים (שער, ריבוע, אנכי); טקסט חלופי (alt) לכל תמונה – חובה לנגישות.
5. **תכני עמודים** – עריכת בלוקי דף הבית, הסיפור שלנו, עמודי מדיניות; עורך טקסט עשיר פשוט.
6. **חנויות** – כתובת, טלפון, שעות פתיחה רגילות ומיוחדות (חגים), קישור ניווט.
7. **פניות** – רשימת הפניות מהטופס, סטטוס טיפול, ייצוא.
8. **הגדרות אתר** – לוגו, טלפון, וואטסאפ, רשתות חברתיות, מתג מצב אתר, תגיות SEO כלליות.

**חוויית עריכה:** תצוגה מקדימה לפני פרסום, שכפול מוצר או קולקציה כבסיס לחדש, וביטול מחיקה (סל מחזור ל־30 יום).

## דרישות לא־פונקציונליות

- **מובייל תחילה:** רוב הגלישה צפויה מהטלפון – תפריט קצר, כפתורים גדולים, תתי־קטגוריות באקורדיון, כפתור וואטסאפ צף.
- **נגישות:** עמידה בתקן הישראלי 5568 (WCAG 2.0 AA): ניגודיות, ניווט מקלדת, alt לכל תמונה, הצהרת נגישות.
- **ביצועים:** תמונות בפורמט WebP, טעינה עצלה, גדלים מותאמים למסך; טעינת עמוד מתחת ל־3 שניות במובייל.
- **SEO:** כתובות קריאות לכל קטגוריה ומוצר, כותרת ותיאור מטא נערכים, מפת אתר אוטומטית, נתונים מובנים למוצרים.
- **פרטיות:** טופס צור קשר עם תיבת הסכמה לא מסומנת מראש ומדיניות פרטיות; איסוף מינימלי של מידע; באנר עוגיות אם יופעלו כלי מדידה. בשלב המכירה – סליקה חיצונית מאושרת, ללא שמירת פרטי כרטיס באתר.
- **שפה וכיווניות:** עברית RTL; שמות המותגים באנגלית. תשתית שתאפשר שפה נוספת בעתיד.
- **גיבוי ואבטחה:** HTTPS, גיבוי יומי של מסד הנתונים והמדיה, עדכוני אבטחה שוטפים.

## שאלות פתוחות ללקוחה

התשובות לשאלות אלה קובעות את בחירת הפלטפורמה ואת מבנה הנתונים כבר עכשיו, גם אם המכירה תעלה רק בעתיד.

**מבנה ותוכן**

- [ ] האם "קשתות" בקישוטים ו"עליוניות וקשתות למודולרי" הם אותם מוצרים?
- [ ] מהם שבעת סוגי הבסיסים, ולאילו כובעים/מטפחות מתאים כל אחד?
- [ ] כמה מוצרים צפויים בהשקה, ומי מצלמת ומעלה אותם?
- [ ] האם בגדי בית (CLOA) מגיעים במידות, ואיזו טבלת מידות?

**לקראת מכירה**

- [ ] האם כובעים בהתאמה אישית יימכרו אונליין, או יישארו בהזמנה דרך החנות/וואטסאפ?
- [ ] האם המלאי משותף לחנויות בירושלים ובבני ברק ולאתר? האם יש קופה/מערכת מלאי קיימת שצריך להתחבר אליה?
- [ ] אפשרויות מסירה: משלוח עד הבית, איסוף עצמי מהחנויות, נקודות איסוף?
- [ ] חשבונית: איזו מערכת הנהלת חשבונות קיימת (חשבונית ירוקה, iCount וכד')?
- [ ] מחירי סיטונאות: האם תידרש בעתיד גישה נפרדת ללקוחות סיטונאיים עם מחירון משלהם?
- [ ] מדיניות החזרות והחלפות, במיוחד למוצרים בהתאמה אישית.
